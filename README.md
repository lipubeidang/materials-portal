# 新材料门户与内容发布系统

依据三张参考图片和 PLAN.md 实现的第一版项目。包含公开门户、内容管理后台、操作员与普通人员、本地账号以及中心统一认证适配。

## Linux 服务器启动

服务器先安装 Git、Docker Engine 和 Docker Compose 插件，并启动 Docker 服务。当前用户须有运行 Docker 的权限。Java、Node.js、Maven 和 MySQL 由容器提供，首次构建需要访问依赖和镜像仓库。

```bash
git clone https://github.com/lipubeidang/materials-portal.git
cd materials-portal
cp deploy/.env.example deploy/.env
nano deploy/.env
```

编辑 `.env`：替换 `MYSQL_ROOT_PASSWORD`、`DB_PASSWORD`、`BOOTSTRAP_PASSWORD` 的占位密码，填写 `BOOTSTRAP_USER`，将 `APP_ORIGIN` 改为实际 HTTPS 访问地址。不接中心登录时保持 `CENTER_ENABLED=false`。密码如含 `$` 或 `#`，可在 `.env` 中用单引号包住完整值，避免插值或注释解析。不要上传真实 `.env`。

新数据库会按上述用户名和密码创建操作员；要沿用原登录信息，在这里填写原用户名和密码即可。无需复制 Windows 账号文件、H2 数据库和测试图片。生产配置已关闭演示内容，只初始化默认栏目和站点设置；已有数据库的账号密码不会被初始化设置覆盖。

配置完成后，在项目根目录启动：

```bash
bash ./start.sh
```

该脚本检查 Docker/Compose 和配置文件，构建并后台启动数据库、后端和前端。它不会安装 Docker、配置域名或申请 HTTPS 证书。启动命令完成不等于所有接口已通过验收。

将服务器上的 HTTPS 反向代理指向 `http://127.0.0.1:8090`，并放行所需 HTTPS 入口。浏览器访问地址必须与 `APP_ORIGIN` 一致；后台地址为该域名加 `/operator`。8090 仅绑定服务器本机，不能直接通过服务器公网 IP 访问。

```bash
# 查看状态和日志（在项目根目录）
docker compose -f deploy/compose.yml ps
docker compose -f deploy/compose.yml logs --tail=100
# 停止服务，保留数据库和上传文件
docker compose -f deploy/compose.yml stop
```

Docker/MySQL/HTTPS 部署仍须在目标 Linux 服务器验证。Windows 的 `.cmd` 和 `.ps1` 本地启动脚本不提交到此仓库。

## 已实现的功能

### 门户

- 蓝白门户首页、轮播、最新资讯、站内搜索、外部资源服务的六项数据统计。
- 数据资源使用可搜索的多级目录树和数据集查询空表布局；目录内数据暂留空。接口与配置说明见 [数据资源接入说明](docs/resource-integration.md)。
- 新闻中心、通知公告、领域动态、数据资源、数据产品、交流合作、关于我们。
- 栏目列表、内容详情、单页、资源产品卡片、附件下载。
- 交流合作按七类展示图片入口与分页文章列表；后台从文章正文、封面或图片附件选择分类首页图，发布后同步生效。详见 [交流合作发布说明](docs/COOPERATION.md)。
- 单一主导航、子栏目筛选与面包屑；居中阅读区，封面及图片附件直接展示，列表简介可留空自动生成。
- 登录注册、个人中心、移动端布局与折叠导航。
- 前台页面共用统一尺寸的页头、导航、内容版心和页脚。公共页脚显示中心标识、可配置备案号、版权信息及累计访问量；每次打开、刷新或切换前台页面计 1 次，后台页面及仅切换页内锚点不计入。统计从功能启用时开始，保存在数据库中，重启服务后保留；这是浏览次数（PV），不是去重访客数。

### 内容管理

- 左侧栏目树，右侧搜索、状态筛选、分页列表。
- 图文、单页、资源、产品和外链内容类型。
- 富文本编辑、封面 3:2 居中裁剪、正文图片、附件。
- 正文优先的编辑表单，可折叠的更多设置，图片附件缩略图及一键插入正文；预览与前台展示一致。
- 保存草稿、预览、发布、发布更新、撤回、回收站和恢复。
- 已发布版本与编辑稿独立：改稿不会自动改变前台内容。
- 乐观版本检查，避免覆盖其他操作员的更新。
- 批量发布、批量撤回，逐项报告失败结果。
- 栏目、导航、逐张图文轮播、文章首页图片、快捷入口、建设单位图片、备案号及页脚配置。
- 操作日志。首页推荐引用原内容，撤回后立即停止公开。

### 登录与权限

- 本地注册、密码哈希、安全会话、退出、修改密码和其他会话失效。
- 普通人员无法访问操作员接口，服务端不接受注册请求中的角色提升。
- 中心授权码与 PKCE、SM4、回调防重放、账号关联、令牌加密存储、在线检查、单次刷新与统一退出接收。
- 中心身份第一次登录创建普通账号，不按同名自动合并，不自动授予操作员权限。
- 绑定本地账号须先验证本地密码，再验证中心身份。

**中心功能目前通过本机模拟协议测试，未连接真实中心。** 需要中心完成应用登记、提供实际参数并确认协议差异后，才能宣布真实免登录接入完成。详见 `docs/center-integration.md`。

## 开发与验证

前端：

```powershell
cd frontend
npm ci
npm run dev
npm run build
```

后端（另一个终端）：

```powershell
cd backend
mvn test
mvn package
java -jar target/materials-portal-1.0.0.jar
```

直接启动后端不会自动创建默认密码账号。首次安装需设置 `BOOTSTRAP_USER`、`BOOTSTRAP_PASSWORD`；演示数据需显式设置 `DEMO_DATA=true`。首次初始化后不覆盖已有密码。

本地采用 H2 文件数据库，数据位于 `backend/data`，方便不安装数据库就能运行。正式环境采用 MySQL，配置及部署文件见 `deploy/`。H2 和 MySQL 共用 Flyway 迁移脚本；MySQL 部署仍需在目标环境验证。

## 目录

```text
frontend/     Vue 3、TypeScript、Tiptap、Vite
backend/      Spring Boot、JDBC、Flyway、认证与内容接口
deploy/       Docker Compose、生产环境配置样例
docs/         操作说明、接入清单、验证记录和截图
.runtime/     本机依赖缓存、随机开发账号、运行日志（不提交）
```

前后端接口、内容版本和文件权限均在后端实现，不能将本项目当作仅静态页面部署。

## 使用边界

- 这是单站点、单后端实例的第一版；刷新锁和限速目前在单进程内生效，不适合未经改造直接扩为多实例。
- 文件上传支持 PNG、JPG、PDF、UTF-8 TXT，单文件 10 MB。未开放任意 Office、压缩包、SVG 或可执行文件上传。
- 首页采用通栏轮播、搜索统计、新闻／公告、资源／产品、建设单位和深色页脚布局。可以调整内容、图片、排序和推荐；增加全新首页区域需要新增组件。领域动态保留独立栏目入口。
- 栏目管理支持父子关系，导航及后台目前主要展示两级；请使用最多两级的栏目结构。
- 未配置的数据检索、在线研发、留言等外部业务不显示虚假功能入口。
- 不含多级审核、定时发布、第三章人员部门同步、短信邮件服务。
- 图片和示例文字为演示内容，正式上线前请替换品牌、资料和联系方式。

设计与实现记录见上级目录 `PLAN.md`，实际验收结果见 `docs/VERIFICATION.md`。
