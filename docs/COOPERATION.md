# 交流合作页面与发布方式

交流合作首页使用左侧分类目录、右侧两列分类图片。默认分类依次为学术会议、学术期刊、国际交流、标委会活动、联盟活动、人才培训、企业合作。栏目名称、路径、顺序和启用状态沿用后台“栏目设置”。分类标题、图片、“更多”和左侧目录均进入相应分类的文章列表，点击文章进入详情。

分类列表显示文章标题、来源和显示日期，默认每页 10 条，可切换 20 或 50 条。页码、每页条数保存在地址参数中，刷新和浏览器后退可恢复。置顶、展示优先级、日期沿用现有文章排序。

## 管理者操作

1. 在内容管理左侧选择“交流合作”或其子栏目，点击“添加内容”。
2. 在编辑页面选择具体的“交流合作分类”，填写标题、来源、日期和正文。新发布和发布更新都必须归入具体分类。
3. 插入正文图片、上传内容封面或添加图片附件后，在右侧“交流合作首页图片”选择一张现有图片。该设置独立于站点总首页的“首页图片／推荐到首页”。
4. 横向照片可选“铺满区域”；海报、期刊封面可选“完整显示”，预览会即时更新。
5. 保存草稿不会改变公开页面；点击“立即发布”或“发布更新”后，文章和图片一起生效。

同一分类有多篇文章时，优先采用手动选图的已发布文章；多个手动选择之间，按置顶、展示优先级、显示日期排序。没有手动选图时，按相同排序寻找带图文章，并依次尝试内容封面、正文第一张图、图片附件。无可用图片时显示分类占位卡片，仍可点击进入列表。图片撤回、文章删除或栏目停用后不再用于公开展示。

编辑时移除选中的原图会恢复自动选图；服务端也会校验所选图片确实属于当前文章，且不是 PDF、文本或外部地址。

## 数据升级

新安装由 Bootstrap 初始化七个分类。已有安装通过 `V5__cooperation_categories.sql` 补齐缺少的分类，保留已有同名子栏目的名称、路径、排序、启用状态和内容，不修改历史文章版本。

升级前直接归属“交流合作”顶级栏目的已发布文章仍可通过首页下方“其他交流资讯”阅读。后台标记“待归入子栏目”，由管理者按内容选择具体分类后发布更新；系统不猜测历史文章的分类。

本次收到两张页面参考图，分类首页和文章列表按这两张实现；文章详情沿用现有阅读页面。
